# Getting Started

Since Drippy is just an addon for FancyMenu, most of the time it's the right thing to use [FancyMenu's docs](https://docs.fancymenu.net), that's why Drippy's docs are so empty.

# How To Access Drippy's Customization Screen

To access the customization screen, simply click on the button in the main menu that looks like the loading screen!

This will open a screen that looks like the loading screen. From there it works like normal FancyMenu. You click on the **Customization** tab in the menu bar at the top, and then create a new layout for the current screen (which is the loading screen in that case).

> [!IMPORTANT]
> If you can't see Drippy's button in the main menu, toggle on your FancyMenu customization overlay (the menu bar) via **CTRL + ALT + C**, because the button is anchored to FancyMenu's normal overlay.
